# Contributing to aethelnet-core

Thanks for helping out! 🙌

1. Open an issue (or comment on one) so we agree on the approach first.
2. Branch: `fix/…`, `feat/…`, `perf/…`, `docs/…`, `ci/…` or `research/…`.
3. One topic per PR. Small PRs get merged faster.
4. `pytest -q` must pass locally and in CI. Setup in [AGENTS.md](AGENTS.md).
5. Changing the math? Update the README equations in the same PR and add a test.

Research contributions (experiments that confirm *or refute* a claim) are very welcome:
put them under `research/` with a short write-up of the method and result.

Security issues: please follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

AI-assisted contributions follow the same rules as everyone else. Show test output, don't just claim it works.
